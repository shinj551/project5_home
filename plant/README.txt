RARE AUTUMN PLANTS — VS CODE PROJECT

1. Unzip the project.
2. Open the folder rare_autumn_plants in VS Code (File > Open Folder).
3. Open index.html. Use the Live Server extension's "Open with Live Server", or open index.html in a browser.
4. Edit text in index.html, colors and layout in style.css, and the expand/collapse behavior in script.js.
5. Photos are genuine Wikimedia Commons photographs loaded over the internet; internet is needed to view them. Photo sources and license information are in credits.html.
6. To publish to GitHub Pages, upload index.html, style.css, script.js, credits.html to the repository root and enable Pages.

PROJECT FILES:
index.html — page content and structure
style.css — typography, colors, layout, responsive mobile styles
script.js — interactive buttons
credits.html — photo sources
